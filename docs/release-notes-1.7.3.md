# 栖序 1.7.3 · 老板键，回到待办设置

- 待办主界面左侧新增「老板键」按钮，无需先进入影音模式即可调整切换快捷键、口令和可选访问验证。
- 老板键设置已从影音模式设置中移出；设置窗口不会展示视频、书籍、历史记录或观看内容。
- 需要验证时，修改设置须提供当前口令。保存、关闭、重启后继续保留。
- 支持 Esc 或「返回待办」关闭设置。切换到设置会暂停并静音已有视频，保留观看位置；待办组件继续显示。
- 继承鼠标恢复后键盘直接生效、爱看固定入口、网站增删保存与退出前保存最新进度等修复。
