# 栖序 1.7.6 测试记录

日期：2026-10-24。Windows x64，Electron 41.10.7。模拟页面与真实站点结果分开记录。

## 自动化通过

- 44 项源码测试：字幕解析、新转录组件、虚拟列表合并、广告输入范围、迟到回调、数据持久化和既有回归。
- 新版 YouTube 字幕组件与 Trusted Types 策略：使用真实本地量化模型翻译，中英字幕在播放器中显示，窗口内全屏仍保留字幕。
- 可信输入广告按钮：仅接受 isTrusted 的跳过按钮被 Chromium 原生输入触发；关闭跳过开关后不再点击。模拟页面通过不能代替真实广告实测。
- 关闭置顶后的原生窗口失焦：隐藏、暂停、静音，隐藏期间进度不前进；恢复继续同一播放器及原进度。
- 用户手动暂停后隐藏恢复保持暂停；开启置顶后失焦保持显示；紧急隐藏可恢复。

## 真实 YouTube 观测及限制

- 已尝试两个真实、有字幕轨道的视频。视频曾正常播放；切换原生窗口时隐藏、暂停、静音及恢复在真实视频上通过。
- 部分播放在约一分钟后出现原站「出了点问题，请刷新或稍后重试」；不记为持续播放通过。
- timedtext 接口返回空内容；原站转录请求返回 HTTP 400。正常手动点击原站「内容转文字」同样返回 HTTP 400，因此当前网络／测试会话下真实双语字幕未通过。修复版显示具体接口错误，不将其报告为翻译成功。
- 当前真实测试没有取得可确认的自动跳过结果；不可跳过广告不属于自动点击范围。可信按钮与开关逻辑已通过集成测试，真实广告仍标为未验证。
- 独立会话副本的登录状态不能代替实际账户验证；安装保留 Cookie 数据文件，未操作登录认证。

本记录不承诺所有 YouTube 视频、账号或地区均可用。私有备份、Cookie、用户任务及观看记录不进入公开源码包。
