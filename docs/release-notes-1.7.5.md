# 栖序 1.7.5 · 刚刚好的距离

本次更新围绕影音体验和窗口隐私感做稳定性改进，让 YouTube 播放和应用切换更自然。

- **YouTube 跳过广告：** 当播放器出现可以使用的「跳过广告」按钮时，栖序会独立检测并尝试点击。不可跳过的广告仍按网站规则播放。
- **中英双语字幕：** 扩展 YouTube 原有与自动生成字幕的读取方式；常规播放器接口不存在时，可尝试从页面当前视频信息读取字幕轨道；请求失败后限频重试。字幕仍通过本机离线模型翻译，不会对无字幕视频进行语音识别。
- **窗口失焦自动隐藏：** 关闭「置顶」时，点击其他应用会让影音窗口隐藏、暂停并静音；重新移回原区域可恢复。不会因打开栖序内部登录弹窗而误隐藏。
- **置顶模式：** 开启后可保持窗口在其他应用上方，不因切换焦点而隐藏。主界面及「设置 → 外观与窗口」均可调整。
- **数据兼容：** 兼容既有任务、随手记、书库、阅读位置、浏览网站与账号会话。影音播放位置继续按既有机制保存与恢复。

安装 Qixu-Setup-1.7.5-x64.exe（Windows 10/11 x64）。已安装版本可覆盖升级，升级前建议保留既有应用数据备份。

**适用范围：** YouTube 播放行为和字幕接口由网站控制，实际可用性可能随视频、地区、账号状态及网站改版变化。字幕需要视频提供可读取轨道和本地翻译模型；站点弹出的广告不承诺全部自动跳过。安装包未进行商业代码签名；内置的非商业模型按其独立许可使用。
