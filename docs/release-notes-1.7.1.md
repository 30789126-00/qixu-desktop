# 栖序 1.7.1 · 今日有序，片刻从容

栖序将四象限待办、桌面小组件、轻量影音浏览和沉浸式本地阅读，收进一个 Windows 桌面空间。

### 不止待办，也是属于你的片刻从容

- **把重要的事摆在眼前**：四象限拖动任务、桌面小组件、随手记、下班倒计时与加班计时。
- **切换到喜欢的内容**：哔哩哔哩、YouTube、番茄小说及网页标签，支持窗口透明度、窗口内全屏和快捷隐藏。
- **接着上次看**：保存窗口布局、已打开的页面、本地小说阅读进度及部分视频播放位置；意外退出后尝试恢复会话。
- **自己的书架**：TXT / EPUB 导入、书签、目录、主题、排版和自动滚动。
- **阅读外文更自然**：本机 CPU 网页翻译，以及在能获取视频现有字幕时显示双语字幕。

### 安装

下载下方 `Qixu-Setup-1.7.1-x64.exe`，适用于 Windows 10 / 11 x64。已有安装于 `F:\栖序` 的设备会保留原有安装位置；新设备默认安装到当前用户的应用程序目录。升级设计会保留任务、书库、阅读记录、网站会话及设置，但重要数据仍建议自行备份。

安装包包含约 900 MB 的本地翻译模型，因此体积较大。模型许可为 CC BY-NC 4.0，仅适用于相应许可允许的使用场景；源码仓库没有包含模型权重。

**说明：** 网页登录、视频播放和字幕获取受各网站自身策略及网络限制；双语字幕不代表所有视频都可用。UI 解锁口令不能替代文件加密。安装包暂未进行商业代码签名，Windows 可能提示“未知发布者”。
