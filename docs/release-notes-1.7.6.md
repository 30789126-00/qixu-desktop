# 栖序 1.7.6 · 字幕看得见，切换更从容

修复 YouTube 已读取、已翻译却不显示双语字幕的问题，并验证关闭置顶后的隐藏和播放恢复。

- 支持 YouTube 新版转录字幕组件、虚拟列表和中文「内容转文字／转写文稿」入口。页面字幕请求失败时，继续尝试原站提供的文字记录。
- 字幕层使用安全 DOM 创建，兼容 YouTube Trusted Types 策略；中文译文和英文原文挂载在播放器内部，窗口内全屏仍然可见。
- 可跳过广告增加 Chromium 原生点击，不依赖翻译任务，也能处理仅接受可信输入的按钮。关闭自动跳过后停止点击；不可跳过广告遵循原站规则。
- 关闭置顶时，切换到其他窗口会隐藏影音、暂停并静音。恢复沿用同一播放器和进度；手动暂停保持暂停。开启置顶时保持显示。
- 覆盖升级保留任务、设置、书库、阅读位置、网站 Cookie 和原观看进度。

安装 Qixu-Setup-1.7.6-x64.exe（Windows 10/11 x64）。字幕依赖原视频提供可读取字幕，不进行语音识别。真实站点可能因网络、账号、地区或接口限制暂不可用；自动化模拟页面的通过不等于所有 YouTube 视频都已实测通过。
