# 栖序 1.7.1

今日有序，片刻从容。待办、桌面组件与影音阅读使用同一个安装程序。

## 安装与打开

运行发布页下载的 `Qixu-Setup-1.7.1-x64.exe`。全新安装默认进入 Windows 当前用户的程序目录；此前已安装在 `F:\栖序` 的设备继续沿用旧路径。桌面“栖序”快捷方式用于日常打开。升级保留任务、书库、设置和各网站登录数据。

默认打开待办。按 **Ctrl+Alt**，输入 **WSAD**（不分大小写）并按 Enter，进入影音阅读。再次按 **Ctrl+Alt**，仅影音阅读窗口及其网页弹窗隐藏，待办主窗口和桌面组件保持原状，保留原来正在使用的其他软件；视频暂停、声音关闭。再按一次 **Ctrl+Alt** 恢复影音阅读窗口，无需重复输入密码。手动暂停的视频保持暂停。手动隐藏后鼠标经过原区域也不会恢复。重新启动、显式返回待办或锁屏休眠后需要重新验证。

## 待办与桌面组件

保留任务列表、四象限、开始/截止时间、逗号批量创建、框选、批量编辑及撤销。进入影音模式后，已开启的桌面组件继续显示并可编辑；主动关闭的组件不会因为切换模式被重新打开。

在“四象限”视图，按住任务卡片文字区域的鼠标左键，拖到目标象限后松开，即更新象限并保存；目标区域会高亮。可拖到空象限，也可先选中多个任务后拖动其中一个批量移动。移到象限外松开或按 Esc 取消；Ctrl+Z 撤销移动。空白处拖动框选，Ctrl/Shift 从任务上拖动仍用于追加框选。完成勾选框和编辑按钮继续保留原有操作。

组件的“打开完整清单”返回待办并重新锁定影音入口。鼠标进入组件时，影音仍按移出规则隐藏暂停；组件位置、透明度和置顶独立保存。

## 随手记

随手记输入栏只用于本次编辑，完全退出或重新打开组件后留空；最近保存的内容显示在输入栏下方，始终只保留一条。4 个非空白字符起覆盖保存，标点计数；0～3 个字符不覆盖之前的记录。停止输入约半秒自动保存，关闭组件或完全退出时也会立即保存符合条件的内容。点击“保存记录”可保存并清空输入栏。

## 来源与浏览器入口

保留 YouTube、哔哩哔哩、番茄小说，移除抖音、西瓜视频、好看视频和维基文库入口。新增 Google 浏览器和 Yandex 浏览器：以 App 内网页方式搜索和浏览，支持地址栏、前进后退、透明度、隐藏及内置翻译；不是外部 Chrome 或 Yandex 桌面程序。升级保留现有账号 Cookie，不删除已移除网站的会话数据。

影音模式现已使用真正的多标签浏览器结构：每个网页标签保留独立的 WebContents，会话不会因为切到主页或另一个标签而销毁。切换标签时，离开的标签自动暂停并静音；切回时仅恢复原本正在播放的标签，并保留视频时间。顶部标签支持关闭，`Ctrl+Tab` / `Ctrl+Shift+Tab` 可前后切换；最后一个网页标签关闭后回到摸鱼主页。

浏览器工具栏增加页内查找（`Ctrl+F`）、当前网页收藏、书签列表、浏览历史和手机模式。手机模式只改变当前标签的 User-Agent，关闭后恢复原桌面 User-Agent。历史与书签仅保存在本机，登录表单和网站会话仍按来源隔离。

## 隐藏、全屏与登录

- 鼠标移出影音窗口约 150 毫秒后隐藏、暂停并静音，回到原窗口区域停留半秒恢复。用户手动暂停的视频不会自动续播。
- Ctrl+Alt、侧栏“隐藏影音”和关闭按钮仅隐藏影音阅读窗口及其网页弹窗；Ctrl+Alt+Space 也可紧急隐藏。只有 Ctrl+Alt 会快捷恢复。顶部“待办”或托盘“打开待办并锁定影音”是显式打开完整清单的入口，会重新上锁。单击托盘图标优先恢复当前影音／小说，不关闭原页面。托盘也可完全退出。
- 选择视频或本地小说后自动收起侧栏，通过“展开导航”临时展开。
- “窗口内全屏”和网站的全屏仍限制在 App 窗口内，右上角半透明控制条提供播放／暂停、静音、退出全屏和隐藏，Esc 也可退出；退出后保持原大小。播放器整体容器进入全屏，保留原站播放控件及双语字幕。
- 登录前点击网址栏旁的“登录操作中”，临时关闭鼠标自动隐藏；扫码或验证完成后点击“完成登录”。紧急隐藏始终有效。

各网站使用独立的持久会话，不与系统浏览器自动共享。升级不主动退出已有账号；网站自身的到期、验证码和风控由原站决定。具体登录验收结果见测试记录。

## B 站视频与窗口找回

B 站及其他普通网页的新开标签链接在 App 主内容区打开，不再分离成无法被主工具栏控制的小窗口。账号验证仍可使用受控登录弹窗。

如果自动隐藏后没有看到窗口，按 Ctrl+Alt、单击系统托盘的栖序图标，或再次打开桌面“栖序”快捷方式，均恢复当前窗口并带到前面；不关闭、重载当前视频，也不重新打开小说。恢复不会永久改变置顶设置。鼠标返回仍在原区域停留约半秒恢复。任务窗口和桌面组件不因影音隐藏而消失。TXT 和 EPUB 隐藏时暂停自动阅读、保存进度，恢复保留阅读位置。

## YouTube 自动跳过广告

默认开启。原站广告出现可见、可用的“跳过广告”按钮时自动点击，不可跳过或仍在倒计时的广告等待原站开放按钮。设置中的“播放体验 → YouTube 自动跳过广告”可关闭。不修改广告时间或伪造广告完成状态；网站更新播放器结构后可能需要更新适配。

## 自动中文翻译与双语字幕

各网站默认自动翻译非中文可读取文本，显示原文与简体中文对照，搜索结果及动态新增段落也会处理。App 内新开的网页窗口同样使用内置翻译。首次升级到 1.3 会开启网页翻译和双语字幕并清除旧网站例外，之后仍可按需关闭。图片文字、受保护内容、无法识别或模型不支持的语言不能保证翻译。点击“恢复原文”关闭当前网站的自动翻译，再次点击“翻译此网站”恢复。设置中的“语言与字幕”可关闭自动翻译或移除网站例外。登录表单、密码、验证码和编辑区域不翻译。

视频默认开启中英双语字幕：英语视频保留英语并生成中文；其他支持的外语字幕生成中文和英文；中文字幕不重复叠加。字幕跟随暂停、倍速和进度跳转，支持普通播放、网站网页全屏及窗口内全屏。通过“双语字幕：开/关”控制。

YouTube 优先读取字幕轨道，也接收原站播放器正常请求的原生字幕响应，失败时尝试播放器已经显示的字幕。其他网站使用 HTML5 字幕轨道。仅支持已有字幕，包括原站自动生成字幕；没有字幕、字幕无法读取或语言不支持时显示原因，不进行音频识别。首次加载模型及新字幕翻译需要时间，未完成会显示“翻译中”。广告期间不叠加正片字幕，正片开始后继续。

本版使用免费本地模型，无需 API 密钥，网页及字幕文本在电脑上处理。模型约 917 MB，随安装包提供，运行时需要额外内存，速度取决于电脑。字幕优先于网页翻译；隐藏或锁定后取消旧任务。返回待办或切换到书架、设置时释放翻译进程，避免后台持续占用模型内存。模型损坏或加载失败可点击“重试”，仍失败时重新运行安装包修复。

模型为 NLLB-200 量化版本，CC-BY-NC-4.0，本交付面向个人非商业使用。模型卡与校验记录位于安装目录 `resources\models`。不依赖沉浸式翻译插件或云端翻译服务。

## 小说与设置

TXT、EPUB 导入后复制入书库，支持目录、搜索、书签、继续阅读和自动滚动。字体、行距、阅读宽度及主题可调整。整体不透明度 20%～100%，支持置顶、自定义网站和隐藏快捷键。

开机自启默认关闭；开启后登录 Windows 启动至托盘，不自动进入影音。待办与影音共用自启设置。

## 数据与备份

沿用 `%APPDATA%\Moyu` 兼容旧书库。`todo` 保存任务，`library` 保存小说，`state.json` 保存设置和进度，`Partitions` 保存各网站会话。完全退出后备份整个目录可以保留完整状态；不要分享包含登录会话的备份。

1.2 使用首次迁移备份比较旧待办与栖序的变化，合并新增任务；冲突任务另存并标注“旧待办保留版本”。合并记录和原文件快照在 `migration-backup`。本机部署验证合并完成后清理旧待办程序及旧桌面入口，数据备份保存在工作区。两个版本不会长期同时运行。

访问验证是本地入口锁，不额外加密图书和浏览器缓存。登录诊断只记录流程与错误状态，不记录验证码、密码和 Cookie。

## 开发与复现

Windows x64、Node.js 22.12+、系统 .NET Framework 4.x。执行 `npm ci`、`node scripts/prepare-models.cjs`、`npm run build`、`npm start`。模型脚本固定上游版本并验证上游哈希，安装包已经包含模型。

`npm test` 验证核心逻辑与迁移；`scripts/qixu-1.7-smoke.cjs` 验证隐藏恢复、窗口内全屏、视频与小说崩溃恢复；`scripts/browser-benchmark-smoke.cjs` 验证多标签、后台暂停静音、历史/书签、页内查找和手机模式；`scripts/tourbox-smoke.cjs` 验证模拟快捷键不会误唤醒。`native/TodoHost.exe --self-test` 与 `--ui-test` 验证原生待办。`npm run package` 生成安装包，`node scripts/deliver-qixu.cjs` 输出交付文件并复制安装包到桌面。

1.4.1 为字幕单独保留翻译队列，网页翻译繁忙时仍读取字幕。YouTube 原生字幕响应无法读取时尝试展开网站自带的文字记录；无可用字幕时显示原因，不进行语音识别。原文字幕在译文就绪前保留。

## 避免剪辑控制器误唤醒

1.4.2 起，键盘上单独按下 Ctrl+Alt 并松开才切换观影模式；Ctrl+Alt 加其他按键不会触发。Windows 标记为软件注入的模拟按键会被忽略，避免 TourBox 等控制器宏误唤醒。快捷键不拦截、不吞掉，剪辑软件仍能收到按键。已验证 Windows 模拟输入；未直接测试用户的 TourBox 硬件及其配置。托盘找回窗口继续可用。

## 下班倒计时与彩色待办

主界面左侧与桌面组件均提供“下班倒计时”。输入有效的 24 小时制时间（如 18:30），停止输入约半秒即自动同步保存；移开焦点、关闭窗口或完全退出时也会补存，不必再点击“设置”。“设置”和 Enter 仍可立即保存，重启后保留。默认 18:00；每秒根据电脑当前本地时间刷新，按小时／分钟显示，尚不足一分钟按一分钟显示；到点后显示“已加班 ×小时×分钟”，跨午夜持续累计，不按零点清零；单独退出或重开栖序也会保留本轮计时。电脑关机后再次开机或重新启动时，开始新的当天计时，下班时间设置保留。睡眠、休眠继续累计。例如下班时间 19:00，未关机到次日 12:00 显示“已加班 17小时0分钟”。输入无效时间不会覆盖之前的设置。

待办采用奶油黄与淡紫渐变底色、葡萄紫导航、薄荷绿添加区和不同象限的彩色任务卡。小组件保持透明度与置顶设置，开始／截止时间选项默认收起，需要时展开。

## 1.6.1 自启动修复

开启后注册当前安装版栖序的 Windows 登录启动项，使用 `--autostart` 参数。自动启动会显示桌面待办组件，完整待办和影音窗口保持收起。开关写入后读取 Windows 实际结果，重新打开待办也会同步系统状态；Windows 中手动禁用启动项时，应用显示关闭。升级后若已开启但注册项缺失，会补建启动项。关闭开关会删除栖序的登录启动命令。

## 1.7.0 会话恢复与稳定性升级

- 影音模式改为明确的窗口状态机：待办、解锁、显示、自动隐藏、紧急隐藏、最小化与休眠各自独立，快捷键隐藏后再次恢复不会误切回待办。
- 返回待办时保留当前网页会话；重新解锁直接继续原页面。完全重启或异常退出后，会恢复上次来源、网址、视频时间和原播放/暂停意图。
- B 站与 YouTube 使用独立播放器适配，窗口内全屏直接扩展播放器容器，不改变 App 外层窗口大小，播放、暂停、静音和退出全屏继续可用。
- TXT/EPUB 阅读进度继续自动保存；会话检查点额外保存当前书籍，异常退出后重新解锁会自动回到同一本书及保存位置。
- `state.json` 改为临时文件写入、校验、原文件备份后原子替换；启动时主文件损坏会自动尝试临时副本及 `.bak` 备份。另有 `session.json` 标记正常退出与异常退出，用于崩溃恢复。
- 隐藏影音时立即读取一次实际播放器时间并写入检查点，降低轮询间隙造成的进度回退。
