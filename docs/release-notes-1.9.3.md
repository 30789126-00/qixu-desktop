# 栖序 1.9.3 · YouTube 播放中断自动恢复

本次修复针对 YouTube 视频播放一段时间后偶发出现的 **“Something went wrong. Refresh or try again later.”** 错误画面。

- **播放器内错误识别：** 除了原有的网页加载故障，现在还能识别 YouTube 播放器的可见错误提示和媒体解码／网络错误。
- **自动重试：** 在正在观看的视频出现错误后，短暂等待并刷新；如果错误提示消失但视频仍未继续播放，会继续尝试。单次故障最多自动刷新两次，避免无限循环。
- **断点续播：** 恢复时保存最后一次有效的观看时间和播放意图；错误界面短暂出现的 0 秒或暂停状态不会覆盖原有断点。
- **尊重用户操作：** 用户主动暂停或切换视频后，不继续上一段视频的自动恢复任务。
- **诊断信息：** 本地 `playback-diagnostics.log` 只记录故障阶段、时间、错误类型和哈希视频标识，不记录 YouTube URL、Cookie 或请求数据。

修复只在栖序的 YouTube 影音标签内生效。网络不稳定、网站服务故障、视频访问权限和 YouTube 自身限制仍可能导致无法恢复；两次尝试后应用会提示手动检查网络或刷新。

安装包：**Qixu-Setup-1.9.3-x64.exe**，Windows 10 / 11 x64。覆盖安装保留原有用户数据、浏览器会话、阅读与观看进度。详见 [本版测试记录](test-record-1.9.3.md)。
