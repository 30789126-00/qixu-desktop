- 52 项自动化单元/逻辑测试；TypeScript、原生待办与语音桥接编译、生产构建通过。

## 范围与限制

- 用户 EPUB、正文截图、真实数据备份与账号会话仅保存在本机，不进入公开源码或 Release。
- 公开复现脚本默认使用仓库内原创 EPUB；可通过 `QIXU_EPUB_FIXTURE` 指定自己的本地文件。`QIXU_EXECUTABLE` 可指定安装版，测试另建隔离数据目录。
- 未进行整夜听书、数小时内存趋势或全部 Windows 语音设备组合测试；扫描图片无文字的 EPUB 不含 OCR，无法直接朗读图片内容。
- 本版没有改变 YouTube 播放器或翻译实现；相关单元测试回归通过，不将历史真实站点测试写成本次新实测。
