# 栖序 1.7.2 · 为片刻从容，留一条捷径

## 老板键，按你的习惯切换

- 初次使用可设置切换快捷键、访问口令，并选择是否需要验证。
- 以后在「设置 → 老板键」调整；使用「轻盈暂离」「切换快捷键」「访问验证」等名称。
- 修改口令或关闭验证需要验证当前口令；新口令区分大小写，以随机盐和 scrypt 派生值保存，不保存明文。
- 已有用户沿用原口令、快捷键、数据与观看位置。原 WSAD 口令仍不区分大小写，直到主动修改。
- 使用其他快捷键后，原 Ctrl+Alt 停用；快捷键冲突会提示，并保留原快捷键。

## 延续 1.7.1 的修复

- 鼠标移回后激活窗口并聚焦网页，无需再点击即可使用网站提供的空格、方向键等播放器按键。
- 网站增删立即保存，完整退出后继续保留；永久加入「爱看」https://ikapp.com/。
- 隐藏时暂停并静音，唤回保留播放和阅读位置。

## 安装与反馈

下载 Qixu-Setup-1.7.2-x64.exe，适用于 Windows 10/11 x64。旧版安装到 F:\栖序 的设备会原位升级；新版保留任务、书库、网站会话与设置。安装包内置本地翻译模型，约 825 MB；请核对 SHA256。

访问验证仅用于界面切换，不提供本地文件加密。站点播放、登录与字幕受原网站支持和网络环境限制。翻译模型遵循 CC BY-NC 4.0，安装包暂无商业代码签名。
