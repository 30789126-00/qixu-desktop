# 栖序 1.9.3 功能与操作

## YouTube 自动恢复

在栖序的 YouTube 影音页面正常观看视频。如果播放途中出现 “Something went wrong” 等播放器错误，栖序会尝试重新加载当前页，并在视频准备好后恢复到报错前的观看位置。

恢复包含以下规则：同一个故障最多自动刷新两次；恢复后需要确认播放时间持续前进才算成功；错误画面的进度与暂停状态不覆盖已有观看记录；主动暂停、切换视频和切换到其他来源时不持续为旧视频重试。两次失败后可以手动刷新，或检查站点、网络与账号限制。

本地诊断日志在应用数据目录 `%APPDATA%\\Moyu\\playback-diagnostics.log`。仅保留时间、事件、错误类型和视频哈希标识。
