# 栖序 1.9.0 · 安心接着读，从容安排每一天

这次更新围绕长时间使用：书越读越顺，任务按周期出现，数据有保存反馈，也有可找回的副本。

## 阅读，更连贯

- **长书轻装阅读：** EPUB 释放远处章节的解析文档，保留正在显示及相邻章节；全文索引在后台建立，同一本书更换关键词和重新打开时复用索引。
- **排版跟着当前句：** 调整字号、行距、宽度或窗口大小时，以具体文字位置校准阅读区域。修复初始化重排覆盖目录选择、隐藏听书后旧页面覆盖进度的竞争问题。
- **听书更好控制：** 提前准备下一句，支持上一句／下一句、当前句提示、分钟定时和本章结束停止。仍可选择隐藏后继续听书。
- **书架更清楚：** 提取 EPUB 正式书名、作者和封面，支持手动编辑书名作者，以及待读／在读／已读筛选。
- **按需打开：** 阅读器和数据维护页面独立加载，减少待办界面首次启动的前端资源。

## 日常，更有章法

- **周／月重复待办：** 可设置间隔；完成后准备下一期，到期也会自动生成。错过多个周期时合并补到最近一期，避免重开后堆出大量过期副本。
- **项目与标签：** 编辑任务时填写项目和多个标签，按项目、标签与关键词组合筛选，保留四象限拖动和撤销。
- **每天下班时间：** 按星期设置不同时间，也可临时覆盖当前工作日。电脑跨夜未关机时继续原工作日的加班计时。

## 浏览，更省心

- **闲置标签休眠：** 可配置时间、网站例外，支持手动休眠后台标签。切回重新加载并恢复可读取的视频进度；登录操作和未提交表单尽量避免休眠。
- **每个视频分别续看：** 保存独立进度，主页提供继续观看；B 站不同分 P 和带剧集片段的网址分别记录。
- **翻译缓存有边界：** 限制内存和磁盘缓存，按模型版本隔离复用结果，减少重复翻译。
- **可选性能诊断：** 记录隐藏／恢复状态及耗时，可导出排查偶发问题；不记录网址、书名、任务正文或 Cookie。

## 数据，更踏实

- **自动保存与重试：** 显示保存时间；保存失败保留待写内容并自动重试，退出前确认落盘。
- **应用内备份与恢复：** 待办中的“数据与版本”可创建备份、预览恢复差异；恢复前留下回滚点。包含网站会话的备份会正常重启一次，适用于本机同一 Windows 用户。
- **更新与回退：** 查看 GitHub 稳定版说明，自行下载，通过 SHA256 校验后安装；保留已有安装包供后续版本回退。安装前先保存并创建数据回滚点。
- **固定回归矩阵：** 将原生待办、隐藏焦点、全屏、异常恢复、长书、字符定位及备份恢复串成可重复执行的测试。

安装包：**Qixu-Setup-1.9.0-x64.exe**，Windows 10 / 11 x64。覆盖升级沿用数据目录，保留任务、书库、网站会话、阅读位置和设置。

更多操作见 [使用说明](使用说明.md)，验收范围见 [测试记录](test-record-1.9.0.md)。第三方网站的登录、字幕和播放能力依原站条件；本版不含语音识别。版本回退只更换程序，若要恢复旧数据，请预览并选择对应数据回滚点。
