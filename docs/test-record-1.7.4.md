# 栖序 1.7.4 测试记录

验证环境：Windows x64，Electron 41.10.7，2026-10-23。桌面测试使用独立数据目录与测试口令。

## 老板键入口

- 首次安装未完成设置：待办按钮保留，关闭引导、关闭设置及完整退出重启后仍能打开。
- 无效快捷键保存失败：入口保留，原配置不被覆盖。
- 设置快捷键并启用口令：保存后待办按钮立即隐藏，影音设置显示表单，重启后保持。
- 设置快捷键但关闭口令：待办按钮仍隐藏，影音设置仍可更改，重启后保持。
- 未设置快捷键、已经选择免口令：待办按钮保留；成功保存快捷键后隐藏，重启后保持。
- 旧版默认 Ctrl+Alt / WSAD 保持可用，未主动设置的旧版用户保留待办设置入口；1.7.2/1.7.3 已保存设置迁移到影音设置。
- 错误口令、修改口令、关闭验证的口令校验和快捷键占用提示通过；快捷键冲突不会注销原快捷键。
- 待办和设置引导期间内容接口保持锁定，公共状态不包含密码记录，磁盘不保存明文口令。
