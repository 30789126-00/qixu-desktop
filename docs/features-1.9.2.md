# 栖序 1.9.2 功能与操作

## 影音全屏

1. 在 B 站或 YouTube 播放视频。
2. 点击网站播放器自己的“全屏”按钮，或使用栖序提供的全屏入口。
3. 视频会进入播放器原生全屏，同时只占满**当前栖序窗口**的内容区域。
4. 栖序外层窗口不会进入 Windows 系统全屏，也不会改变原来的位置、宽度和高度。
5. 按 `Esc` 退出后回到进入全屏前的栖序布局。

B 站适配固定使用播放器的“全屏”控制，不使用“网页全屏”。如果站点更新导致原生按钮无法定位，栖序会保持正常布局并提示重试，不会切换到缺少原站播放器控制的伪全屏状态。

全屏切换只改变当前网页视图的布局和站点播放器的 HTML Fullscreen 状态。当前视频 URL、播放时间、用户主动暂停状态、双语字幕任务和网页键盘输入会继续使用同一 WebContents，会话不会因为全屏切换而重建。

## 继承 1.9 系列能力

1.9.2 继续包含 1.9.0 的长书内存控制、全文搜索索引复用、精确阅读定位、听书定时、书架分类、周期待办、项目标签、分工作日下班时间、闲置标签休眠、独立视频续看、翻译缓存、保存重试、备份恢复和应用内更新／回退。

## 第三方站点限制

播放器按钮、字幕接口、登录流程和广告形态由第三方站点控制。栖序不会绕过会员、付费或访问限制。站点修改 DOM 后可能需要重新适配；出现异常时可先退出全屏并刷新当前标签。
