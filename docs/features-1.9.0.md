# 栖序 1.9.0 功能与操作

## 阅读

书架可按“全部／待读／在读／已读”筛选，搜索书名与作者。卡片的管理按钮可编辑正式书名、作者和分类。EPUB 提供封面时自动提取；旧书保留自定义标题，首次读取时补充元数据。

阅读器的耳机按钮打开朗读设置，上一句／下一句可直接回听，正文下方显示当前句。定时选择分钟数后开始计时，换句不会重置期限；“本章结束停止”在逻辑目录章节结束时停止。手动暂停、换书、目录跳转沿用既有规则。隐藏继续听书开关只影响小说声音，视频隐藏仍暂停和静音。

全文搜索首次打开会建立索引并显示进度，之后换关键词或重开书籍复用。单次关键词最多 128 字；最多显示 200 处结果。索引存本机，不上传书籍。单书索引上限 48 MB，总缓存上限 96 MB／20 本，超限会提示；缓存清理后可重新建立。

解析章节按需释放；正在显示的多个页面、相邻章节及短暂被搜索或朗读占用的章节会受保护。封面缓存、朗读历史和下一句预备均有限额。字号或窗口变动时优先保存当前字符和相对高度；书内固定排版、复杂图片等内容可能无法像纯文本一样精确。

## 待办与下班时间

编辑任务可填写项目、用逗号分隔的标签，以及每 N 周／每 N 月重复。批量编辑需勾选修改规则。标签筛选是“同时包含”，并与项目和关键词共同生效。

完成周期任务会建立下一期；上一期未完成时，到下一期开始时间也会自动建立。没有开始时间时使用结束时间；两者都没有时以创建日期为基准。应用关闭多期不会生成全部遗漏副本，只补最近一期。每月 31 日在短月落到月底，之后继续使用原来的 31 日。取消重复请修改当前最新一期；删除已生成项不会自动重新生成同一项。

下班卡片的“每周安排”可为星期一至星期日分别设置时间，空白沿用通用时间。临时覆盖只作用于当前工作日。原有“关机后重置工作日”的逻辑保留；跨午夜未关机继续显示已加班时间。

## 标签页与继续观看

影音设置可选择后台标签休眠时间，0 表示关闭；网站例外填写域名。标签页上的休眠按钮只用于后台标签。当前标签、登录操作、受控弹窗及检测到已修改表单的页面不自动休眠。

休眠释放网页进程，保留标签地址和已读取的播放位置。切回后重新加载页面，恢复原有登录会话和视频时间；网站未保存的滚动、表单或应用内部状态无法保证完整复原，因此编辑型网站建议加入例外。

主页“继续观看”按视频分别记录位置；保留最多 500 条。YouTube 按视频 ID、B 站按视频及分 P、其他网站按规范化地址记录。以网站私有播放器保存而无法读取的位置仍受网站实现限制。

## 数据与版本

待办侧栏底部点击“数据与版本”，或在影音设置进入。保存状态会显示最后成功时间；失败时自动重试，也可手动重试。完全退出前会刷新阅读、待办和会话数据；无法保存时明确提示并暂缓退出。

创建备份会产生含 manifest.json 的文件夹，应保留整个文件夹。默认备份任务、书库、设置和阅读／观看进度；选中“包含网站会话”会重启后备份。会话使用系统加密，适合当前电脑和 Windows 用户恢复，不保证跨电脑登录迁移。

恢复前校验所有文件并显示任务数、书籍数、变化文件数及是否包含账号会话。确认后重启，替换对应数据，并保留恢复前回滚点。老板键和口令也会恢复到备份设置；未包含网站会话时保留现有账号。恢复中断会尝试回到恢复前的完整数据。

检查更新仅读取固定 GitHub 仓库的稳定版。下载和安装分开确认；安装前检查大小、SHA256 和文件格式，先创建数据回滚点，再退出安装。安装过的新版安装包会保留供以后回退；没有历史安装包时不会显示旧版回退项。回退程序不会自动回滚数据，新版字段在旧版中可能不生效，必要时选择相应数据回滚点。

窗口诊断默认关闭，开启后最多保留 500 条状态／耗时记录；关闭即清空。诊断不包含网址、正文、账号内容，可手动导出。

## 开发回归

构建后执行 npm run test:matrix。测试串行使用隔离数据，避免指针和窗口焦点相互干扰。设置 QIXU_EXECUTABLE 可对已安装的程序执行同一矩阵；QIXU_EPUB_FIXTURE 可指定仅在本机使用的私有测试书。真实跨屏与系统缩放需在对应硬件环境补验，48 组 DIP 几何输入测试不等同于改变显示器的物理配置。
