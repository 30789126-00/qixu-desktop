# 栖序后续改进建议（待用户选择）

以下依据 1.8.0 源码、当前交互和本轮测试提出，尚未实施；不是已确认的故障清单。先选择项目，再单独确定范围，避免一次改动过多导致回归。

## 优化现有功能

| 编号 | 建议 | 依据与收益 |
|---|---|---|
| O01 | EPUB 内存缓存设定上限 | 朗读和搜索会加载章节文档；数百章长书应只保留当前与相邻章节，按预算释放其余文档，降低长时间阅读的内存增长。 |
| O02 | 全文搜索建立可复用索引 | 目前 EPUB 每次更换搜索词都逐章读取。后台索引配合取消正在加载的章节，可减少重复扫描和长书等待。 |
| O03 | 缩放与排版定位细化到当前句 | 已保存 CFI/段落位置，但改变字号、窗口宽度时可进一步保持当前句在屏幕中的相对高度，减少视觉跳动。 |
| O04 | 朗读提前准备下一小段 | 当前采用短段落串行衔接；限定只预备下一段，测量段间空隙，在不增加大量内存的前提下改善听书连贯性。 |
| O05 | 本地界面按功能拆包 | 当前前端构建约 716 KB，包含阅读依赖；书库、阅读器和设置按需加载，可降低首次打开影音空间的解析负担。 |
| O06 | 不活跃网页标签按需休眠 | 现有独立网页标签保留会话，也持续占用内存。提供可选休眠和站点例外，保存页面及时间后再回收，切回时明确恢复。 |
| O07 | 保存失败增加重试与状态反馈 | 目前主要通过提示文字报告保存异常；应支持退避重试、显示最后成功保存时间，并防止失败被下一条通知遮住。 |
| O08 | 翻译缓存增加容量与生命周期控制 | 在现有优先队列上，限制网页和字幕缓存总量，并按模型版本使缓存失效，减少重复翻译及长期占用。 |
| O09 | 隐藏与恢复延迟做可关闭的性能记录 | 只记录状态和耗时，不记网页正文或账号内容；能区分鼠标检测、窗口显示、网页暂停哪一步慢，更容易定位偶发顿感。 |
| O10 | 固定播放器和多屏回归矩阵 | 把原站可控样例与离线播放器样例分开，覆盖多 DPI、跨屏、失焦、全屏、手动暂停和恢复。避免一个站点适配改动影响其他窗口行为。 |

## 修改或新增能力

| 编号 | 建议 | 具体使用价值 |
|---|---|---|
| M01 | 应用内备份、预览与恢复 | 让用户自行导出任务、书库和设置，恢复前看到差异并保留回滚点。账号会话与普通数据分开选择；不承诺跨电脑迁移登录状态。 |
| M02 | EPUB 高亮、批注与摘录导出 | 在书签之外保存具体文字与笔记，用阅读位置锚定，并可导出 Markdown，适合知识类书籍。 |
| M03 | 听书睡眠定时器 | 支持若干分钟后或本章结束后停止；隐藏继续朗读开启时，也能避免忘记关闭而一直播放。 |
| M04 | 朗读上一句、下一句与当前句提示 | 在现有暂停/继续上增加精细回听；显示当前朗读句，方便没听清时返回，而不是重新开始整段。 |
| M05 | 书架元数据、封面与阅读状态 | 从 EPUB 提取正式书名/作者/封面，允许手动修正，并提供待读、在读、已读分组；减少长文件名和散乱书架。 |
| M06 | 重复待办 | 支持每周、每月或自定义日期重复，完成后生成下一次任务，适用于例行工作；与现有开始/截止提醒配合。 |
| M07 | 待办项目与标签 | 在四象限优先级之外增加项目归属，支持组合筛选；任务多时不必依赖标题关键词区分不同工作。 |
| M08 | 按工作日设置下班时间 | 一周不同日期可使用不同时间，并允许临时覆盖当天；保留目前跨夜累计加班的规则。 |
| M09 | 每个视频独立的继续观看记录 | 当前会话以最近一个页面/时间为主；增加按视频保存的续看列表，多个标签和剧集切换后也能分别回来。 |
| M10 | 应用内更新检查与版本回退入口 | 只在用户同意后下载、校验并升级；显示变更说明，升级前备份，出现问题可找回上一版安装包。 |

建议顺序：先 O07、O01、O10，降低数据与稳定性风险；再 O04、M03、M04 改善听书；其余按实际使用频率选择。功能范围确认前不自动实施这些建议。
