# 栖序 1.9.0 测试记录

测试平台：Windows x64、本地 Electron 41。所有破坏性测试、恢复测试和崩溃测试使用独立数据目录；用户提供的私有书籍仅留在本机，不进入源码与公开附件。

## 核心逻辑

- 66 项 Node 测试通过：覆盖保存失败后的最新快照重试、缓存 LRU／字节限额／过期、翻译缓存跨重启及模型版本隔离、章节引用保护、句级朗读、隐藏定时停止、独立视频地址、备份篡改／路径／中断回滚、更新下载与安装前哈希校验，以及既有鉴权、会话、字幕和广告跳过逻辑。
- 几何矩阵覆盖 48 组输入：100%／125%／150%／200% 对应 DIP 工作区、负坐标副屏、已断开的屏幕位置、超小及超大窗口。此项为逻辑输入测试，不等同于实际更改显示器缩放。
- 原生待办自测与 UI 测试通过：重复任务自动生成／幂等、月末锚点、完成与撤销、项目和标签组合筛选、每周下班时间、锁文件保存失败重试，并回归四象限 12 方向拖动、框选、随手记与倒计时。

## 集成与性能

- 360 章 EPUB：第一次索引约 0.7 秒，更换关键词约 0.4 秒（包含 300 ms 输入防抖）；重新打开复用 IndexedDB。测试时保留的章节 XML 文档为 2 个。
- 20 MB UTF-8 TXT：首屏约 0.9 秒，首屏挂载 12 个段落；60 秒自动滚动记录 7,199 帧，P95 帧间隔 8.5 ms，最大约 16.6 ms，末尾挂载 18 个段落。此为该机该次测量，不是所有设备的帧率保证。
- TXT／EPUB 字号、行距、宽度及大小窗口字符定位通过；修复初次重排覆盖导航、隐藏朗读旧页面覆盖进度、TXT 列表测量过早写回进度、标签唤醒尚未加载即覆盖续看位置，以及分数缩放下解锁尺寸取整漂移。
- 私有 EPUB 验证 540×600 与 1260×900 两种窗口的第三章标题、目录开关、向前回读、本机中文语音、手动暂停、隐藏跨段跨章、到书末停止及重启 CFI。
- 两个离线视频分别保存 9 秒／21 秒位置；休眠销毁原 WebContents，唤醒创建新实例并恢复位置；后台静音、用户手动暂停状态和主页续看列表通过。
- 备份创建、差异预览、正常重启恢复、恢复前回滚点、账号会话关闭后备份、书架分类与封面、受限 IPC，以及诊断脱敏导出通过。
- 版本回退界面的确认、保存、备份、安装请求和重新校验通过；下载服务以固定测试响应验证大小与 SHA256，损坏安装包被拒绝。本机 NSIS 覆盖升级与安装包保留也经验证。

## 安装与数据

1.9.0 覆盖安装沿用原目录。安装前正常保存退出，完整复制数据和旧程序并逐文件校验；原有任务、书库文件、Cookie 数据库、老板键、设置、阅读位置及观看进度在正常重启后核对保留。桌面快捷方式及安装包更新。逐文件清单和包含隐私的数据备份仅保存在本机工作区。

固定命令：构建后执行 npm run test:matrix；QIXU_EXECUTABLE 指向安装版时运行相同矩阵，私有 EPUB 通过 QIXU_EPUB_FIXTURE 提供。测试串行执行，以避免鼠标焦点相互干扰。

## 尚有环境限制的范围

- 实际多显示器热插拔、各种物理 DPI 混合组合、硬件休眠／关机、TourBox 实体设备和数小时内存趋势需要对应环境补验。模拟坐标、软件注入按键与有限时长压测分别记录，不替代硬件实测。
- 本次主要回归生命周期及缓存，没有重新对真实账号逐站扫码登录。Cookie 文件保留可证明原登录资料未被清理，服务器仍可能自行使会话过期。
- 广告／字幕协议用可控播放器夹具验证；真实网站可能改变按钮、字幕权限、网络和登录条件。此前真实平台结果不冒充本次新实测。
- 真实跨版本降级后的所有旧字段组合未逐一遍历。应用先留下数据回滚点；旧版对新字段的支持取决于旧版本。没有历史安装包时不显示可回退版本。
- 不承诺零故障或所有书籍固定像素定位；复杂固定排版、图片型 EPUB、网页私有播放器与未保存网页状态有各自限制。
