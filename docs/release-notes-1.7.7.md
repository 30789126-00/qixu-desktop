# 栖序 1.7.7 · 双语字幕回到正轨

在 1.7.6 的播放器、广告按钮与安全字幕层修复基础上，解决 YouTube 自动中文轨覆盖英语原字幕的问题。

- **自动恢复英语原轨：** 开启双语字幕后，如果 YouTube 将英语字幕自动翻成其他语言，栖序会切回英语原字幕，再通过本机模型生成中文。避免把自动中文字幕误判成无需处理。
- **避免字幕串轨：** 忽略英语原轨迟到的其他语言自动翻译响应；字幕缓存按语言区分。
- **保留稳定交互：** 可跳过广告自动处理；关闭置顶后失焦隐藏、暂停、静音，恢复继续同一视频和进度；手动暂停不会被强制续播。
- **覆盖升级保留数据：** 任务、设置、书库、账号 Cookie、阅读和观看位置均继续保留。

已使用现有登录会话以普通 Electron 运行方式验证：无需手动切字幕，真实 YouTube 视频的英语原文与本地中文译文均显示；本次测试观察到广告自动跳过。仍只处理原站提供可用跳过按钮的广告，字幕需要视频本身提供可读取字幕。

安装 Qixu-Setup-1.7.7-x64.exe（Windows 10/11 x64）。
