# 栖序 1.7.4 · 老板键入口，随设置而变

- **尚未设置快捷键：** 待办侧栏保留「老板键」按钮，首次引导关闭后也能继续设置。
- **已保存快捷键：** 待办不再显示该入口，后续在影音模式的「设置 → 老板键」更改。
- **口令由你选择：** 开启或关闭访问验证均不影响入口位置；快捷键、口令和入口状态在重启后保留。
- 兼容旧版默认快捷键与已有自定义设置，升级保留任务、随手记、书库、阅读位置、网站会话和视频进度。
- 继续保留鼠标恢复后键盘直接生效、爱看固定入口、网站增删保存和退出前保存播放进度等改进。

下载 `Qixu-Setup-1.7.4-x64.exe`，适用于 Windows 10/11 x64。已有 `F:\栖序` 安装沿用原路径覆盖升级。内置离线翻译模型，安装包约 825 MB。
