# 栖序 1.8.0 · 故事，也可以听

目录点到哪里，就从哪里开始读；收起窗口，也可以继续听。

- **章节定位更可靠：** 修复 EPUB 把标题和正文分为不同页面时，点击目录却看不到章节标题的问题。小、大窗口及目录面板开关会重新适配正文尺寸。
- **本地书籍语音朗读：** TXT、EPUB 从当前段落开始，连续跨段和跨章节，支持选择 Windows 本机语音与语速、暂停、继续和停止。书籍文字不发送到在线语音服务。
- **隐藏后听不听，由你选择：** 默认隐藏时暂停、恢复后继续。阅读器耳机按钮中可开启“隐藏后继续朗读”；返回待办、锁屏、休眠或退出仍会停止。视频隐藏时的暂停、静音规则保持原样。
- **续读更稳定：** 目录连续切换只采用最后一次请求；修复返回书架时保存回调重新打开原书的问题。完整重启恢复阅读位置和朗读偏好，但不会自动开始出声。

安装包：`Qixu-Setup-1.8.0-x64.exe`，Windows 10 / 11 x64。覆盖升级保留任务、书库、网站会话和设置。

使用方法：打开本地书籍，点击底部“语音朗读”；右上角耳机按钮可设置声音、语速和隐藏行为。若未检测到语音，请先通过 Windows 安装相应语言的语音，再重启栖序。图片扫描型 EPUB 需要书内包含可读文字，本版不含 OCR。
